## 🔧 **How to Create PDF & DOCX:**

### Method 1: Using Google Docs (Recommended)
1. **Copy** the content from `Fahad_Khalid_Resume_ATS.txt`
2. **Paste** into a new Google Doc
3. **Format** using these settings:
   - Font: Arial or Calibri, 11pt
   - Margins: 1 inch all sides
   - Line spacing: 1.15
   - Bold the section headers
4. **Download as PDF** and **DOCX**

### Method 2: Using Microsoft Word
1. **Open** Microsoft Word
2. **Paste** the content from the text file
3. **Apply formatting**:
   - Font: Calibri 11pt
   - Bold section headers
   - Proper spacing between sections
4. **Save as PDF** and keep DOCX version

### Method 3: Online Converters
1. Use **Pandoc** online converter
2. Upload the markdown file
3. Convert to PDF and DOCX
